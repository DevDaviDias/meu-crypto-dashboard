
# 📊 Dashboard de Criptomoedas
Um dashboard interativo que exibe os preços e a variação de algumas criptomoedas em tempo real, além de permitir visualizar gráficos dos últimos 7 dias.

#### link do projeto : https://devdavidias.github.io/meu-crypto-dashboard/

## 🔹 Funcionalidades

- Exibe os preços atuais de Bitcoin, Ethereum, Binance Coin, Dogecoin e Solana.
- Mostra a variação percentual das últimas 24 horas.
- Atualização automática a cada 15 segundos.
- Gráfico interativo com histórico de preços dos últimos 7 dias.
- Interface moderna e responsiva, compatível com dispositivos móveis.

## 🛠 Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)
- [Chart.js](https://www.chartjs.org/) para gráficos
- API [CoinGecko](https://www.coingecko.com/) para dados de criptomoedas
